# Week 04 – Deep Learning: Industrial Defect Detection

## Project Overview

This project implements image classification for industrial casting products using deep learning and classical machine learning techniques.

## Dataset

**Dataset:** Real-Life Industrial Dataset of Casting Product

**Source:** [Kaggle Dataset](https://www.kaggle.com/datasets/ravirajsinh45/real-life-industrial-dataset-of-casting-product)

The dataset contains images classified into two categories:
- `def_front` – Defective casting products
- `ok_front` – Non-defective casting products

## Models Implemented

1. Convolutional Neural Network (CNN) from scratch
2. MobileNetV2 Transfer Learning
3. Logistic Regression baseline

## Evaluation

Models are compared using:
- Test accuracy
- Precision, recall and F1-score
- Confusion matrices
- Training time
- Inference latency

## Technologies

Python, TensorFlow, Keras, scikit-learn, NumPy, Pandas, Matplotlib, Seaborn and Jupyter Notebook.

## How to Run

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Download the dataset from Kaggle.
5. Extract the dataset and configure the dataset paths in the notebook.
6. Run the notebook cells in order.
